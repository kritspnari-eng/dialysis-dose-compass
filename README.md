# Dialysis Dose Compass

ช่วยปรับปรุงส่วนแสดงผล "แผนการกระจายขนาดยา" ในฝั่งขวาของหน้าจอ โดยเปลี่ยนจากการแสดงข้อความธรรมดา ให้แสดงเป็น **ตารางปฏิทินการฉีดยารายสัปดาห์และรายเดือน (4 สัปดาห์)** ที่ดูง่ายและชัดเจน ดังนี้:

1. **ตารางกระจายการฉีดยารายวัน (ใน 1 สัปดาห์):**

   - สร้างตารางแนวนอนแบ่งตามวันฟอกเลือด:

     - หากเลือก `2 ครั้ง/wk` ให้แสดงคอลัมน์: **วันจันทร์** | **วันพฤหัสบดี** | **รวม/สัปดาห์**

     - หากเลือก `3 ครั้ง/wk` ให้แสดงคอลัมน์: **วันจันทร์** | **วันพุธ** | **วันศุกร์** | **รวม/สัปดาห์**

   - ในแต่ละช่องวัน ให้ดึงข้อมูลจาก `Suggested_Regimen` มาแยกแสดงขนาดยาที่ต้องฉีดในวันนั้นๆ ตัวใหญ่ๆ (เช่น `2,000 IU` หรือ `งดฉีด`) พร้อมระบุหมายเหตุหากมีเศษยาเหลือในขวด (เช่น `*เหลือยา 0.5 vial*`)

2. **ตารางสรุปแผนรายเดือน (สัปดาห์ที่ 1 - 4):**

   - สร้างตารางสรุป 4 แถว (สัปดาห์ที่ 1, สัปดาห์ที่ 2, สัปดาห์ที่ 3, สัปดาห์ที่ 4) และแถวสุดท้ายเป็น **รวมทั้งหมดต่อเดือน (4 สัปดาห์)**

   - แสดงคอลัมน์: **สัปดาห์ที่** | **ขนาดยารวม (IU)** | **จำนวนขวด/เข็มที่ใช้ (`Vials_Per_Week`)** | **หมายเหตุการเบิก/เปิดขวดยา**

   - ในแถวสรุปรวมท้ายตาราง ให้แสดงยอดรวม `Target_Weekly_IU * 4` (IU/เดือน) และจำนวนขวด/เข็มรวมทั้งเดือน (`Vials_Per_Week * 4` ขวด/เข็ม) แบบตัวหนาเน้นสีให้เห็นชัดเจน

3. **อัปเดตข้อความสำหรับ Copy Note:**

   - เมื่อกดปุ่ม "คัดลอกสรุปคำสั่งยา (Copy Note)" ให้จัดรูปแบบข้อความสรุปวันฉีดยาและยอดรวมรายเดือนให้เรียงบรรทัดสวยงาม พร้อมนำไปวางในระบบเวชระเบียนได้ทันที ช่วยปรับปรุง "ตารางกระจายการฉีดยารายสัปดาห์" ให้แสดงคอลัมน์ครบทั้ง 6 วัน ตั้งแต่วันจันทร์ถึงวันเสาร์ พร้อมตัวเลือกจัดรอบวันฟอกเลือด ดังนี้:

1. **เพิ่มตัวเลือก "รอบวันฟอกเลือดของคนไข้" (Dialysis Days Pattern):**

   - หากความถี่เป็น `2 ครั้ง/wk` ให้มีปุ่มเลือก: **จันทร์ - พฤหัสบดี** หรือ **อังคาร - ศุกร์** หรือ **พุธ - เสาร์**

   - หากความถี่เป็น `3 ครั้ง/wk` ให้มีปุ่มเลือก: **จันทร์ - พุธ - ศุกร์** หรือ **อังคาร - พฤหัสบดี - เสาร์**

2. **โครงสร้างตารางรายสัปดาห์ (6 วัน + ช่องรวม):**

   - แสดงคอลัมน์เรียงตามลำดับ: **จันทร์** | **อังคาร** | **พุธ** | **พฤหัสบดี** | **ศุกร์** | **เสาร์** | **รวม/สัปดาห์**

   - **การลงขนาดยาอัตโนมัติ:** นำขนาดยาแต่ละมื้อจาก `Suggested_Regimen` ในไฟล์ `Dosing_Schedule_Lookup.csv` มาวางเรียงตามลำดับรอบวันที่เลือก (เช่น หากสูตรระบุว่าฉีด 2 มื้อ คือ `4,000 IU` และ `2,000 IU` แล้วเลือกรอบ **อังคาร - พฤหัสบดี - เสาร์** หรือ **อังคาร - ศุกร์** ให้ใส่ `4,000 IU` ในช่องวันอังคาร และ `2,000 IU` ในช่องวันศุกร์)

   - **การตกแต่งช่องในตาราง (Visual Highlight):**

     - วันที่มีการฉีดยา: ให้เน้นพื้นหลังสีฟ้าอ่อนหรือเขียวมิ้นต์ ตัวเลขขนาดยาใหญ่ชัดเจน (เช่น **4,000 IU**)

     - วันที่ไม่มีการฉีดยา: แสดงเครื่องหมาย `-` หรือคำว่า `งด` สีเทาจางๆ เพื่อให้แยกแยะวันฉีดยาได้ทันทีด้วยสายตา

   - แสดงหมายเหตุเศษยาเหลือ (เช่น `*เหลือยา 0.5 vial*`) ที่ด้านล่างของตารางอย่างชัดเจน

3. **อัปเดตข้อความ Copy Note:**

   - เมื่อกดปุ่ม "คัดลอกสรุปคำสั่งยา (Copy Note)" ให้ระบุวันฉีดยาตามรอบวันที่เลือกจริง (เช่น จันทร์ / พุธ / ศุกร์ หรือ อังคาร / พฤหัสบดี / เสาร์) ให้ตรงกับในตาราง เงื่อนไขป้องกันข้อผิดพลาดเพิ่มเติม (Edge Cases):

การปัดเศษขนาดยาตามรูปแบบบรรจุ: หากเลือกยาแบบ PFS ให้ปัดขนาดยาต่อสัปดาห์ให้เป็นพหุคูณของ Strength_IU ของยานั้นเสมอ (เช่น ยา 4,000 IU ให้ลงท้ายด้วย 4,000 / 8,000 / 12,000 และยา 5,000 IU ให้ลงท้ายด้วย 5,000 / 10,000 / 15,000)

กรณีหา Lookup_Key ไม่พบ: หากขนาดยาที่คำนวณได้ไม่มีในตาราง Dosing_Schedule_Lookup.csv สำหรับความถี่ที่เลือก (เช่น 10,000 หรือ 12,000 IU แบบ 2 ครั้ง/สัปดาห์) ให้แสดงข้อความเตือนสีส้มว่า "ไม่พบรูปแบบการแบ่งฉีดสำหรับความถี่ 2 ครั้ง/สัปดาห์ กรุณาปรับขนาดยาหรือเปลี่ยนรูปแบบยา"

การคำนวณส่วนต่างค่ายา: คำนวณจาก max(0, Hosp_Price - ราคาเบิกตามสิทธิ) เพื่อไม่ให้ยอดส่วนต่างที่ผู้ป่วยต้องชำระติดลบในกรณีที่เพดานเบิกสูงกว่าราคาโรงพยาบาล
